Option 1 — Using venv (built into Python 3)
🪜 Step-by-Step

Open Terminal / CMD / PowerShell
Navigate to your project folder:

	cd path\to\your\project


Create a virtual environment

	python -m venv venv


This creates a new folder called venv/ that holds an isolated copy of Python.

Activate the environment

Windows (CMD):

	venv\Scripts\activate


Windows (PowerShell):

	.\venv\Scripts\Activate.ps1


macOS / Linux:

	source venv/bin/activate


You’ll know it’s active because your prompt changes to something like:

	(venv) C:\your\project>


Install packages
Now install libraries only for this project:

	pip install numpy matplotlib


Save dependencies

	pip freeze > requirements.txt


Deactivate when done

	deactivate
